# Phase 13 — LinkedIn Launch Assets

Five images, generated with PIL (titles/layout) and `mermaid-cli` (the
architecture diagram), plus a written launch post. No external image
generation service was used — these are programmatic graphic design, not
photos or AI-generated art, which is the right tool for clean, legible
title cards and diagrams.

## About `dashboard_preview.png`

There is no Power BI `.pbix` file in this project (Phase 8 — Windows-only
software, unavailable in the build environment), so there's nothing real to
screenshot. Rather than fabricate a mockup that looks like a Power BI
dashboard and let people assume it's one, this image is two real matplotlib
charts (from `screenshots/`, generated by querying the actual warehouse) on
a branded background, labeled directly on the image itself: *"No Power BI
dashboard exists for this project... see repo's Known Limitations."* The
label is part of the image, not a caption someone could separate it from.

## Regenerating

All five were built from one script using PIL + the `screenshots/` PNGs +
a `mermaid-cli` render of the architecture flow. The script isn't checked
into the repo (it's a one-off asset generator, not part of the pipeline),
but the approach is: DejaVu Sans/Sans Mono fonts, the same navy/green/gold
palette as `screenshots/`, and the real chart PNGs composited in — not
regenerated from scratch, so the numbers always match whatever the
warehouse actually contains.
